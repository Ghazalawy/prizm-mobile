✅ v1.8.2 Auth Fix — Post-Login Grace Period

The tasks module returning 401 on list is the exact scenario the v1.8.2 post-login grace period protects against:

  1. User signs in → fresh JWT token obtained
  2. Dashboard loads → fires useTasksDueToday() which calls apiRequest("tasks?limit=200")
  3. Server returns 401 (tasks endpoint is permission-gated differently)
  4. WITHOUT fix: handler fires → "Session expired" → user kicked out
  5. WITH v1.8.2 fix: 401 arrives within 5-second grace period → silently ignored

1. Executive Summary

Outcome: multi-status project chips and Perfex funnel AND/OR filters now return the correct combined results. Backend and mobile release v1.14.3 are deployed.

The UI retained multiple selections, but the request serializer flattened them into a direct value such as status=3,5. The Projects controller treated that as one exact value, while funnel grouping and negative operators were lost.

Projects now uses a typed logical filters payload. The API validates an allowlist, applies grouped AND/OR clauses, supports multi-value, negative, comparison, empty and range rules, and keeps legacy comma-separated status requests compatible.

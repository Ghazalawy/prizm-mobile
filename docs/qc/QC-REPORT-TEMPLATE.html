1. Executive Summary

The customer funnel recorded Inactive but the released app sent a Perfex web-table JSON payload that Customers.php does not parse. With no direct active parameter, the API silently applied its active=1 default.

The corrected app sends active=0 for Inactive, active=1 for Active, and include_inactive=1 when both statuses are selected.

Android result: both the quick chip and Funnel → Inactive → Apply returned 17 total; all eight visible rows were Inactive and zero were Active.
